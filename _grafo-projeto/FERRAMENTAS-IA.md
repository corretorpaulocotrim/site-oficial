# Ferramentas de IA (capacidades + cautela)

## Já disponíveis (seguras, uso direto)
- **MarkItDown (Microsoft)** — converte PDF, Word, Excel, PowerPoint, imagem (com OCR), HTML, CSV/JSON
  em Markdown limpo pra IA ler bem. Já instalado no ambiente. Uso pra ler os PDFs de `tabelas/` e planilhas.
- **Assistir vídeo** (ffmpeg → frames) — ler o que aparece na tela de um vídeo. Ver [[ECONOMIA-DE-TOKENS]].

## Criar conteúdo pelo chat (avaliar JUNTOS — cautela)
- **AdCreative / HeyGen HyperFrames** (vídeo 24): geram anúncios, imagens e vídeos com avatar direto do chat
  via conectores. Útil pro marketing do Paulo, MAS exigem conta/chave de terceiros. Avaliar antes de conectar.
- **Metricool (MCP)**: conecta o Claude às redes (Instagram/TikTok/etc.) pra ler desempenho e gerar/agendar posts.
  Endpoint `https://api.metricool.com/mcp`. Exige conta Metricool — avaliar antes de conectar.
