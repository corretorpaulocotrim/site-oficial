# Economia de token (a dor do Paulo)

Como fazer a IA render mais gastando menos — sem risco.

## Práticas seguras (adotadas)
1. **Grafo primeiro.** Consultar [[00-MAPA]] em vez de reler o site inteiro. (Grafiphy — maior ganho.)
2. **`/compact`** — quando a conversa fica longa, comprime o histórico num resumo. Menos token, mesmo contexto.
3. **Planejar com Opus, executar com Sonnet.** Opus faz o plano (poucos tokens de plano); Sonnet executa mais barato. Ver `/model opusplan` em [[COMANDOS-CLAUDE-CODE]].
4. **Mudança cirúrgica** ([[COMPORTAMENTO-KARPATHY]]) — mexer só no necessário gasta menos e quebra menos.
5. **Assistir vídeo (capacidade que já temos):** baixar o vídeo e extrair frames (ffmpeg) pra ler o que está na tela. Foi assim que os vídeos deste projeto foram lidos — não precisa de skill de terceiros (/watch).

## Terceiros — avaliar JUNTOS antes (cautela)
- **OpenClaw / OmniRoute** (gateways grátis p/ DeepSeek/Kimi/GLM/Ollama): cortam custo de API, MAS roteiam sua chave por provedores de fora. **Não instalar no escuro.** Se quiser, a gente avalia um por um.
