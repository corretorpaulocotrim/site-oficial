# Comandos úteis do Claude Code (cola pro Paulo)

Comandos que o Paulo digita na conversa com a IA:

- **/memory** — abre a memória do projeto. Você escolhe e edita o que a IA lembra (sem vícios). Aqui é o [[00-MAPA]] + CLAUDE.md.
- **/agents** — cria/edita agentes especializados (ex.: um só pra revisar, um só pra segurança).
- **/rewind** — volta ao estado anterior. Se um resultado não ficou bom, desfaz sem perder o resto.
- **/plan** — a IA planeja passo a passo ANTES de mexer no código. Bom pra tarefa grande.
- **/goal** — você define o critério de sucesso; a IA fica na meta até atingir.
- **/compact** — comprime a conversa longa num resumo. Economiza token sem perder contexto. Ver [[ECONOMIA-DE-TOKENS]].
- **/model opusplan** — Opus planeja, Sonnet executa (mais barato). Bom pra tarefa grande.

## /grill-me (comportamento adotado)
Antes de tarefa grande/ambígua, a IA **interroga o Paulo** com perguntas afiadas (o que exatamente, em qual página, qual prioridade) e só depois executa. Isso evita retrabalho e casa com [[COMPORTAMENTO-KARPATHY]] (não suponha — pergunte).
